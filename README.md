# Nodebuff Utils

Client-side Fabric mod for Minecraft 26.2 with two 1.7/1.8 PvP input fixes,
each toggleable from Options > Controls (bind the keys) or
`config/nodebuff-utils.json`:

- **Item Use Priority** — right-click starts item use while left-clicking
  (pot instead of punching), with the vanilla hold-repeat throttle intact.
- **Old Eating** — drop-eating: drops register in real time while the eat
  keeps running, and the eating slow-down flickers off per drop (little
  jitters at near-normal speed).
